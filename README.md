# Mon patrimoine

Une app pour suivre mon capital, mon budget du mois et faire des simulations.
Elle s'installe depuis le navigateur sur téléphone et ordinateur, et marche hors connexion.

**Les données restent sur l'appareil.** Ce dépôt ne contient aucun chiffre personnel.
Pour mettre ses données sur un appareil : bouton « Importer » dans l'app, puis choisir son fichier de données (.json).
Pour les sauvegarder ou les passer sur un autre appareil : bouton « Sauvegarder mes données ».

## Mettre à jour l'app
Remplacer les fichiers de ce dépôt par la nouvelle version. Les données déjà sur l'appareil ne sont pas touchées.
